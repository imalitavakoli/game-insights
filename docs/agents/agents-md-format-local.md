# `AGENTS.local.md` format 📎

How to write the gitignored companion of `AGENTS.md`.

**What belongs in it at all** is decided by [where-content-lives.md](where-content-lives.md). This file has **no required headings, sections, or keys.** Free-form prose is the point.

The overlay rule lives on `AGENTS.md` → Developer Workflows: local layers on top of `AGENTS.md`, and where they conflict, local wins. Do not restate that rule here.

A missing `AGENTS.local.md` is the normal state of a clone. Do not create one unless the user asks for a personal instruction.
